# Roopa & Anoop — Wedding Invitation

Mobile-first wedding invite matching the reference video structure: splash envelope, scroll sections, countdown, story timeline, gallery, events, families, venue map, and footer.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize content

Edit [`content/site.json`](content/site.json) for all copy, dates, events, and media paths.

## Replace assets

See [`public/assets/README.md`](public/assets/README.md). Drop your photos, video, music, and illustration PNGs into the listed folders (same paths as in `site.json`).

## Deploy

```bash
npm run build
```

Deploy the `web` folder to Vercel or Netlify (Next.js default).
