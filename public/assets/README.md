# Wedding invite assets

Replace placeholder files with your final artwork. Paths match `content/site.json`.

| Folder | Purpose |
|--------|---------|
| `splash/` | `envelope.png`, `florals.png`, `seal.png` (optional layered open animation) |
| `frames/` | Jharokha frame PNGs: `arch-top.png`, `sides.png`, `balcony.png` |
| `photos/` | Couple photos, `couple-video.mp4`, `couple-poster.jpg`, `moment-*.jpg` |
| `events/` | Event card illustrations |
| `audio/` | `bg-music.mp3` |

Until custom files exist, the site uses CSS/SVG fallbacks and gradient placeholders.
